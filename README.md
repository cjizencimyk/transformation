# Transformation

App perso (PWA, iPhone d'abord) : sport à la maison, nutrition, suivi et coach à règles simples.

- Hébergée via GitHub Pages (branche `main`, racine).
- Données stockées sur l'appareil (IndexedDB + localStorage). Les données de l'ancienne version sont reprises automatiquement.
- Produits : Open Food Facts (ODbL). Polices : Fraunces et Figtree (OFL).
- L'ancienne version reste disponible via le tag `ancienne-version`.
