# Transformation

Programme de musculation à la maison, suivi nutrition et progrès. Application web installable (iPhone : Safari → Partager → Sur l'écran d'accueil), qui fonctionne hors ligne. Les données restent sur l'appareil (IndexedDB), avec export et restauration d'une sauvegarde.

Crédits : produits Open Food Facts (ODbL), icônes Lucide (ISC), illustrations 3D Microsoft Fluent Emoji (MIT), polices Lexend et Unbounded (SIL OFL 1.1), lecture des codes-barres ZXing (Apache 2.0).
